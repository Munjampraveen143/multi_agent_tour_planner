## 🌎 About The Project

**Multi-Agent Tour Planner** is an intelligent AI-powered travel planning application designed to make travel planning easier, faster, and smarter.

It uses multiple AI agents that collaborate to understand user preferences, explore destinations, suggest attractions, organize itineraries, and create personalized travel experiences.

Whether you're planning a weekend getaway or a long vacation, this project helps you plan your perfect trip! 🧳

## ✨ Key Features

- 🤖 **Multi-Agent Architecture** – Multiple intelligent agents collaborate to plan trips.
- 🌍 **Destination Discovery** – Explore exciting destinations.
- 🗺️ **Smart Itinerary Planning** – Generate personalized travel schedules.
- 🏨 **Accommodation Suggestions** – Discover suitable places to stay.
- 🍽️ **Food Recommendations** – Find interesting food experiences.
- 💰 **Budget Planning** – Organize trips according to your budget.
- 🎯 **Personalized Recommendations** – Travel plans based on user preferences.
- ⚡ **AI-Powered Assistance** – Get smarter travel suggestions.

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd multi_agent_tour_planner
```

**3. Create a virtual environment**

```bash
python -m venv venv
```

**4. Activate the virtual environment**

Windows:

```bash
venv\Scripts\activate
```

Mac/Linux:

```bash
source venv/bin/activate
```

**5. Install dependencies**

```bash
pip install -r requirements.txt
```

**6. Configure environment variables**

Create a `.env` file and add the API keys required by your project.

```env
API_KEY=your_api_key_here
```

**7. Run the application**

```bash
python main.py
```
